## 🚀 Featured Project

### 🏛️ [WithLand](https://github.com/JOSHING132/WithLand)
**Fork of [Sharzhukov/WithLand](https://github.com/Sharzhukov/WithLand)**

A **C++17 turn-based colony survival simulator** focused on survival,
resource management, events and colony simulation.

This repository is a fork of the original **WithLand** project by
**Sharzhukov**.

### 🎮 Features

- 👨‍🌾 Farmer / Builder / Medic / Scout / Guard / Mage
- ❤️ Health, damage and death
- 🍖 Hunger and food
- 😊 Mood
- 🦠 Diseases and recovery
- 📅 Daily simulation
- 🌲 Wood harvesting
- 🎒 Stackable inventory
- 🛡️ Armor system
- ⚔️ Random events
- 📜 Game logs
- 🖥️ TUI
- 🎨 Raylib GUI
- 💻 macOS / Linux / Windows

### 🛠️ Built With
