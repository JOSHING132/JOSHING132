# JOSHING132 GitHub Profile

## What is included

```text
README.md
.github/workflows/snake.yml
assets/avatar.jpg
```

## 1. Repository

Create a **public** repository named exactly:

```text
JOSHING132
```

The repository must belong to the GitHub account `JOSHING132`.

## 2. Upload

Upload the files from this package, keeping this path:

```text
.github/workflows/snake.yml
```

The profile README must be named exactly:

```text
README.md
```

Do not rename it to `README(1).md` or anything similar.

## 3. Enable the contribution snake

After the files are uploaded:

1. Open the repository `JOSHING132/JOSHING132`.
2. Open **Actions**.
3. Select **Generate contribution snake**.
4. Click **Run workflow**.
5. Wait until the workflow finishes successfully.

The workflow creates/updates the `output` branch with the generated SVG files.

The README already points to:

```text
https://raw.githubusercontent.com/JOSHING132/JOSHING132/output/github-contribution-grid-snake.svg
https://raw.githubusercontent.com/JOSHING132/JOSHING132/output/github-contribution-grid-snake-dark.svg
```

The snake will not display until the workflow has run successfully at least once.

## 4. Profile avatar

`assets/avatar.jpg` is only an optional copy of the prepared image.

To use it as the GitHub profile picture, upload/select it through:

```text
GitHub → Settings → Public profile → Profile picture
```

## 5. Important

The profile repository is special only because its name matches the username:

```text
JOSHING132/JOSHING132
```

That is what makes GitHub display `README.md` on the user's profile page.
